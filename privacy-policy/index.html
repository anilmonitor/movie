1. Overview

Movie Man is an entertainment discovery and cinema guide application. This service is provided at no cost and is intended for use as an informational catalog to discover movie overviews, release years, ratings, cast information, and categories.

This page informs users regarding our policies with the collection, use, and disclosure of Personal Information for anyone using the Movie Man application.

2. Information Collection and Use

For a better experience, while using our service, the application may access general non-personally identifiable technical information automatically provided by your device operating system:

  • Device Information: Device model, operating system version, and system language settings to properly render application content.
  • Log Data: In case of an error or application crash, diagnostic data (such as device state and error stack traces) may be processed to help identify and resolve technical issues.
  • Local Storage: Saved bookmarks and personal watchlists are stored locally on your device storage and are not transmitted to external servers.

3. Information We Do Not Collect

We respect user privacy and do not collect sensitive user data:
